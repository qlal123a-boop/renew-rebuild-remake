# إصلاح الفشل الأحمر المتكرر في طلبات المبرمج الذكي

## النتيجة المطلوبة
منع المبرمج الذكي من فتح طلب دمج بملفات جديدة غير متناسقة، وضمان أن قائمة الصفحات تُحدَّث قبل فحص TypeScript.

## التنفيذ
- تحديث مولّد الملفات ليضيف محتوى كل ملف ناجح إلى سياق العملية فورًا، حتى تعتمد الملفات التالية على الأنواع والدوال التي أُنشئت فعليًا لا على تخمينات.
- تشديد تعليمات التوليد لمنع استيراد دوال أو خصائص غير موجودة، وللحفاظ على توافق صفحات TanStack الجديدة.
- تعديل فحص GitHub ليجري البناء أولًا لتوليد قائمة المسارات، ثم يفحص TypeScript، ثم يكمل الفحص العام.
- تحسين حالة الفحص في لوحة المبرمج الذكي لتعرض النتيجة الصحيحة بعد طلب الدمج.

## التحقق
- التأكد من نجاح الفحص المحلي الحالي.
- مراجعة سجل البناء بعد التعديلات.
- فحص أن إعداد GitHub الجديد يولّد المسارات قبل TypeScript.

## ملاحظة
الطلبات القديمة الحمراء تحتوي بالفعل على كود غير صالح ولن تتحول تلقائيًا إلى خضراء؛ الإصلاح يمنع تكرار السبب في الطلبات الجديدة.
